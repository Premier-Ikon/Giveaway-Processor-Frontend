# CSV Processor Frontend

A modern, Apple-inspired frontend for processing CSV files and generating giveaway entries.

## Features

- 📤 Drag & drop file upload
- 📊 Automatic column detection
- ⚙️ Customizable multiplier
- ⚡ Real-time processing
- 💾 Automatic CSV download

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The app will open at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

## Usage

1. Upload your CSV file (drag & drop or click to browse)
2. Select the column to use as multiplier
3. Enter the multiplier value
4. Click "Process CSV"
5. Download the processed file automatically

## Tech Stack

- **Vite** - Build tool
- **Vanilla JavaScript** - No frameworks
- **PapaParse** - CSV parsing
- **Modern CSS** - Apple-inspired design
